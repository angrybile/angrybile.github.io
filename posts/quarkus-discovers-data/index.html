Quarkus Discovers “Data”

A new umbrella reduces complexity by adding an additional layer and a migration guide.

The Quarkus team discovered that searching for JPA produced 16 extension results, concluded this was confusing, and introduced Quarkus Data: a new umbrella, a new entry-point extension and a migration path from the thing previously called Panache Next. It is currently experimental.

This is how frameworks mature.

First, create a charming abstraction with a memorable but meaningless name.

Then create reactive and non-reactive variants.

Then integrate a standard that appeared after your abstraction.

Then rename the next version after the generic noun users were searching for in the first place.

Finally, publish a diagram explaining that the additional layer reduces complexity.

To access a database, install quarkus-data-hibernate, unless you need reactive functionality, in which case add another extension, unless you’re maintaining an existing application, in which case Panache remains supported, although new investment goes into Quarkus Data, which will eventually ship with Quarkus 4.

Simple things are now easy.

You just need to identify which generation of “simple” applies to you.
