Micronaut 5: Seventy Modules of Lightweight Simplicity

The application starts rapidly, having transferred all suffering to the build.

Micronaut 5 reached general availability on May 20, 2026. Its platform refresh spans more than 70 Micronaut modules, and the new major version adopted Java 25 as its baseline.

Micronaut began with a compelling idea:

What if we built something lighter than Spring?

Seventy modules later, the answer appears to be:

Spring, but with compile-time introspection and different documentation.

This is the natural lifecycle of every lightweight Java framework.

Version 1:

We are a tiny toolkit.

Version 2:

We added dependency injection.

Version 3:

We added data, security, messaging, cloud integrations and service discovery.

Version 4:

We have our own platform BOM.

Version 5:

Please consult the migration guide covering more than seventy coordinated modules.

It remains lightweight because many expensive decisions happen during compilation.

The application starts rapidly, having transferred all suffering to the build.

Micronaut 5 also requires Java 25, which is admirably modern.

Enterprise users currently migrating from Java 8 to Java 17 can expect to evaluate it shortly before the heat death of the universe.

None of this is criticism.

Micronaut exists to offer Java developers a framework containing every feature they require while allowing them to explain at conferences that they do not use Spring.

This is an essential market.
