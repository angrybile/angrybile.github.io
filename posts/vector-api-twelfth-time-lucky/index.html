The Vector API: Twelfth Time Lucky

The incubator has now spent enough time in school to write its own benchmarks.

JDK 27 contains the Vector API as its twelfth incubator. Its eventual design remains connected to changes being developed by Project Valhalla.

Twelve incubations.

Human children finish primary education in less time.

The API is now mature enough to perform high-performance SIMD computation across multiple hardware architectures, but apparently not mature enough to leave the heated enclosure at the back of the laboratory.

At this point the Vector API should not be released. It should be given a small pension and thanked for its service.

Of course, the delay is entirely justified because it depends on Valhalla, which will provide a transformed object model at some unspecified future point after every existing developer has retired or become a product manager.

Until then, users can choose between:

  1. Using the incubating API.
  2. Writing unsafe native code.
  3. Waiting for the JIT to recognize the loop.
  4. Posting a benchmark proving that option three worked once on their laptop.

Java’s commitment to portability remains absolute.

Your program will run equally suboptimally everywhere.
